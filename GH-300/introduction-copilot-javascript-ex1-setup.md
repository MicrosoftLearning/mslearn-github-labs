In this exercise, you'll:

- Set up a GitHub account and enable GitHub Copilot access.
- Open a JavaScript personal portfolio template in GitHub Codespaces.
- Use a development container preconfigured with Copilot and the project's dependencies.
- Verify that the portfolio starts with `npm start` on port 1234.

## Getting started

When you select the Launch Exercise button link below, you'll be taken to the Codespace creation page for the JavaScript portfolio template. Review the configuration and select **Create new codespace**. Startup can take a few minutes while the required dependencies and extensions are installed.
