In this exercise, you'll:

- Open a React-based JavaScript portfolio template in GitHub Codespaces.
- Customize the portfolio with your information and social media links.
- Use GitHub Copilot Chat or code suggestions to add CSS animations to social media icons.
- Preview the running site and verify the hover animations.

## Getting started

When you select the Launch Exercise button link below, you'll be taken to a preconfigured development environment for the JavaScript portfolio template.

Use the portfolio project to personalize your profile, prompt Copilot to animate the social media icons, and accept or refine its suggestions. The running site reloads automatically as you make changes, so you can preview the results in your browser.

When you've finished the exercise in GitHub, return here for:

- A quick knowledge check.
- A summary of what you've learned.
- A badge for completing this module.
