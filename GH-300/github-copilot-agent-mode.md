In this exercise, you'll:

- Set up GitHub Codespaces and GitHub Copilot to develop OctoFit Tracker, a social fitness app for students.
- Use GitHub Copilot Agent mode to build user profiles, activity tracking, teams, leaderboards, and workout suggestions.
- Practice prompting and refining AI-generated app components.
- Test and optimize the generated code to create a functional prototype.

## Getting started

When you select the Launch Exercise button link below, you'll be taken to a public GitHub Skills template repository that guides you through a series of coding challenges.

When you've finished the exercise in GitHub, return here for:

- A quick knowledge check.
- A summary of what you've learned.
- A badge for completing this module.
