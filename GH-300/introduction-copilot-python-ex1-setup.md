In this exercise, you'll:

- Set up a GitHub account and enable GitHub Copilot access.
- Launch a Python web API template in GitHub Codespaces with Copilot preconfigured.
- Verify that the application starts with `uvicorn` on port 8000.
- Send a sample POST request using the interactive FastAPI documentation.

## Getting started

When you select the Launch Exercise button link below, you'll be taken to the Codespace creation page for the Python web API template. Review the configuration and select **Create new codespace**. Startup can take a few minutes while the required packages and extensions are installed.
