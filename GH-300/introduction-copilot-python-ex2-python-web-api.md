In this exercise, you'll:

- Use GitHub Copilot code suggestions to extend a Python FastAPI web application.
- Generate a Pydantic model for text input.
- Add a POST endpoint that accepts text as JSON and returns a checksum.
- Add any missing imports with Copilot Chat and verify the endpoint using the API documentation.

## Getting started

Use the development container from the [Python environment setup exercise](./exercise-introduction-copilot-python-setup.md). If you haven't created it yet, select the Launch Exercise button link below, review the configuration, and select **Create new codespace**.

In the Python web API project, prompt Copilot to generate the input model and endpoint, review its suggestions, and resolve any missing imports. Open the running application's `/docs` endpoint to confirm that the new route appears and try a request.

When you've finished the exercise in GitHub, return here for:

- A quick knowledge check.
- A summary of what you've learned.
- A badge for completing this module.
