In this exercise, you'll:

- Set up a Python web API project using a GitHub template.
- Launch a GitHub Codespace preconfigured with the GitHub Copilot extension.
- Verify that the web API starts with `uvicorn` on port 8000.
- Set up GitHub Copilot access for the remaining exercises.

## Getting started

When you select the Launch Exercise button link below, you'll be taken to the Codespace creation page for the Python web API template.

Review the configuration settings, then select **Create new codespace**. Startup can take a few minutes while the development container installs the required packages and extensions.

Once setup is complete, the application starts automatically with `uvicorn`. Check the terminal output and the **Ports** tab to confirm that the server is running on port 8000. Use this development container for the remaining exercises in the project.
