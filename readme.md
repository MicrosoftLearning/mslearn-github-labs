# GH-Courses Lab Exercises - Catalog

This repo contains a consolidated catalog of exercises for Microsoft skilling content, used in GitHub Official Courses. These are not the actual exercise instruction files, but used as a landing space for each course and its set of exercises. 

The exercises may be used in both self-paced skilling experiences on [Microsoft Learn](https://learn.microsoft.com) and in Microsoft and GitHub authorized instructor-led training.

## Information for MCTs
**Are you an MCT?** - Have a look at our [GitHub User Guide for MCTs](https://microsoftlearning.github.io/MCT-User-Guide/)

Any MCT (Microsoft Certified Trainer) can submit a pull request to the code or content in the GitHub repro. Microsoft and the course author will then triage and include content and lab code changes as needed. You can submit bugs, changes, improvement, and ideas. Find a new Azure or Microsoft 365 feature before we have? Submit a new demo!
